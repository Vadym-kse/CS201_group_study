План демо-сценарію:

Крок 1. Створюється два об'єкти класу "station"

Крок 2. Створюється 5 об'єктів класу "bike" - два звичайні, три електричні.
"звичайний" та "електричний" - це атрибут "type" класу "bike"

Крок 3. Створється два об'єкти класу "client".
У них є атрибут "balance" - перший = 1000, другий = 2000.

Крок 4. У класу "client" є метод "do_ride()", він робить поїздку.
Туди передається тип велосипеду, станція початкова, 
станція кінцева, час поїздки - це параметри, що передаються у метод.

Цей метод викличеться три рази.

Крок 5. У тому самому методі буде try/except, який може розпізнати
відсутність велосипеду потрібного типу на початковій станції.
Цей блок коду буде викликано.

Крок 6. Буде виведено атрибут "balance" для
кожного об'єкту класу "client".

Крок 7. Буде виведено len(station.bikes).
Це довжина списку велосипедів на кожній із станцій.
А потім буде виведено атрибут "profit" єдиного об'єкту класу "network"
